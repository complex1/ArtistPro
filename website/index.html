GOOD TO KNOW

A little clarity.

Can I use it in a browser?

Yes. Run the renderer and local API for the full creative suite. TapPilot’s profile storage and desktop shortcut execution need Electron. A static website alone cannot run the Python API.

Does it work without an internet connection?

Core creative workflows use local assets and local storage after installation. Setup, updates, optional remote icons, and your phone’s LAN connection have their own network requirements.

Can I move projects between devices?

Tools with project JSON export can create portable editable copies. SVG Studio, Animated Paint, and Cel also keep data in the local API directory; the backup guide explains how to preserve it.

Is it open source?

Artist Studio’s source is MIT licensed. You can inspect it, modify it, and distribute it under that license. Included dependencies carry their own licenses.
